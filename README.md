# lavaluepro.com — LA Value Pro

Static site for **LA Value Pro**, the Los Angeles County desktop appraisal service of Brian Ward Appraisal
(sister sites: [brianward.com](https://www.brianward.com), [date-of-death.com](https://date-of-death.com/)).

- `public/` — deploy root (Cloudflare Pages build output directory). Pure HTML/CSS/JS, no build step.
- `functions/api/` — Pages Functions: `request.js` (order + contact forms via Resend), `form-token.js`.
- `_tools/` — image generation (Gemini) and helper scripts; not deployed.

Pages settings: framework None, build command empty, output directory `public`.
Env vars: `RESEND_API_KEY` (secret), `FORM_SECRET` (secret), `NOTIFY_TO`, `RESEND_FROM`.

Generated by the lavaluepro build (content: 144 LA County cities and communities, 9 service pages, 3 guides).
